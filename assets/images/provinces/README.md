# Province Logos for Vehicle Verification

This directory contains logo images for the different provinces of Pakistan used in the vehicle verification feature.

## Required Logos

You need to add the following logo images to this directory:

1. `punjab.png` - Logo for Punjab Province
2. `sindh.png` - Logo for Sindh Province
3. `kpk.png` - Logo for Khyber Pakhtunkhwa Province
4. `balochistan.png` - Logo for Balochistan Province
5. `gilgit.png` - Logo for Gilgit Baltistan
6. `islamabad.png` - Logo for Islamabad Capital Territory

## Image Requirements

- File format: PNG with transparent background
- Recommended size: 200x200 pixels
- The logos should be simple and clear emblems or symbols representing each province

## If You Don't Have the Logos

Until you add the actual logos, the app will display a fallback icon. To ensure the best user experience, please add the required logo images as soon as possible.
